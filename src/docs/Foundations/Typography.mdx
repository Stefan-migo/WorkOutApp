## Font families

| Token | Stack | Utilities |
| --- | --- | --- |
| `--font-headline` | Inter | `font-headline` |
| `--font-body` | Inter | `font-body` |
| `--font-label` | Inter | `font-label` |
| `--font-mono` / `--font-timer` / `--font-data` | JetBrains Mono | `font-mono`, `font-timer`, `font-data` |

## Text sizes

<Typeset
  fontSizes={['32px', '24px', '18px', '16px', '14px', '12px']}
  sampleText="WorkOutApp — Inter, JetBrains Mono"
/>

| Utility | Size / Line-height | Weight | Usage |
| --- | --- | --- | --- |
| `text-headline-lg` | 32 / 40 | 700, -0.02em | Page titles |
| `text-headline-md` | 24 / 32 | 600 | Section titles |
| `text-body-lg` | 18 / 28 | 400 | Lead paragraphs |
| `text-body-md` | 16 / 24 | 400 | Body copy |
| `text-data-lg` | 20 / 24 | 500 | Numeric stats |
| `text-data-sm` | 14 / 16 | 500 | Data captions |
| `text-label-caps` | 12 / 16 | 700, +0.05em | Caps labels, buttons |
| `text-display-timer` | 84 / 100 | 700, -0.04em | Timer, desktop |
| `text-display-timer-mobile` | 64 / 72 | 700, -0.04em | Timer, mobile |
